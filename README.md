# Yandex Music Downloader GUI (macOS)

Удобное графическое приложение для скачивания треков, альбомов и плейлистов с Яндекс Музыки в максимальном качестве (FLAC/AAC).

## Возможности
- Скачивание в один клик без использования Терминала.
- Поддержка скачивания в FLAC (высокое качество).
- Менеджер аккаунтов (можно сохранить несколько токенов).
- Выбор любой папки на Mac для сохранения музыки.
- Автоматическая очистка ссылок от UTM-меток.

## Как скачать и запустить (Для пользователей)
1. Перейдите во вкладку **Releases** на этом GitHub репозитории.
2. Скачайте архив `YandexMusicDownloader.zip`.
3. Распакуйте его и перенесите `YandexMusicDownloader.app` в папку **Программы** (Applications).
4. При первом запуске macOS может заблокировать программу, так как она без платной подписи Apple. Чтобы запустить:
   - Зайдите в *Системные настройки -> Конфиденциальность и безопасность*.
   - Прокрутите вниз и нажмите **"Подтвердить вход"** (Open Anyway).
